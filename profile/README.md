## Craftavia

Turkish Minecraft network running Towny, Skyblock, BoxPvP, Practice and Survival servers.

🌐 [craftavia.net](https://craftavia.net) · 🎮 `play.craftavia.net` (Java & Bedrock) · 💬 [Discord](https://discord.craftavia.net)

### Open source

| Project | Description |
|---|---|
| [PauseLinks](https://github.com/craftavia/PauseLinks) | Adds your server links and a custom button to the player's pause menu (Paper 1.21.6+). |
| [BedrockMenus](https://github.com/craftavia/BedrockMenus) | Shows any plugin's chest menus to Bedrock (Geyser) players as native forms with item pictures (Paper 1.21.4+). |
| [VillagerCarry](https://github.com/craftavia/VillagerCarry) | Pick up villagers into an egg and place them anywhere, keeping trades and discounts (Paper 1.21.4+). |
| [SeedVeil](https://github.com/craftavia/SeedVeil) | Makes the world seed hard to crack: fake hashed seed, secret bedrock pattern, random structure seeds (Paper 26.x). |
| [GroundItemCap](https://github.com/craftavia/GroundItemCap) | Server-wide cap on dropped items, oldest removed first (Paper 1.21.4+). |

We build our own plugins for performance and stability and share the useful ones for free.
